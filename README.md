
# RoadLink Truck Dispatching

## Project Description
RoadLink is a professional truck dispatching website created
for a Web Development HTML assignment.

The website presents dispatching services, load booking,
rate negotiation, business benefits and a contact inquiry form.

## Technologies Used
- HTML5
- CSS3
- Responsive CSS media queries
- External truck photographs from Unsplash

## HTML Tags Used
- Document structure: html, head, body, title, meta
- Text: h1, h2, h3, p, strong, small, span
- Formatting and navigation: a, br
- Lists: ul, ol, li
- Images: img, alt
- Sections and layout: header, nav, main, section, article, div, footer
- Form: form, label, input, select, option, textarea, button
- Comments: HTML comments

## Project Files
- index.html
- style.css
- README.md

## How to Run
Open index.html in a web browser.
An internet connection is required for the external photographs.

## Important Note
This is a student project and a demonstration business website.
The contact form is not connected to a backend service.
Business claims and service descriptions are illustrative.
